## 🚀 Featured Projects

### 💧 Hydration Monitoring Wearable — Graduation Project
Wearable device that monitors hydration-related physiological signals. An ESP32 reads skin conductance (GSR), PPG (MAX30102) and skin temperature/humidity (SHT30), shows live values on an OLED and streams the data over BLE to a mobile app. Includes a custom PCB designed in KiCad and fabricated, plus a model built from recorded sensor data.
`ESP32` `C++` `BLE` `KiCad` `Sensors`
🔗 [Repository](https://github.com/yagizkorkmaz/hydration-wearable)
